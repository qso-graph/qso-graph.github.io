# Specification

The QSO Graph specification is being rewritten for [QSO Graph Desktop](products.md#qso-graph-desktop).

The earlier version was written for a separate net logger, a direction QSO Graph has since left. It will
be published here again once the rewrite is ready.

The rules that every QSO Graph tool already follows still hold: [ADIF](https://adif.org/) is the base,
ADIF's own definition is used for every field ADIF defines, and credentials stay in your operating
system's keyring.
