Event JSON guide

Run qg-interop listen --wsjtx to emit one QGI-SPEC-001 0.1.0 JSON event per line. The optional --json flag selects the same output. Read one captured native WSJT-X message with qg-interop decode --wsjtx capture.bin, or use - to read standard input. Each capture contains one complete datagram payload, without transport headers.

Every event has spec, family, mapping, kind, context, and fields. WSJT-X observations also have native_version, wire_id, and native. listen receives on a WSJT-X server port, where only WSJT-X instances send, so it supplies direction from_application; decode reads a file whose direction it cannot know, so it supplies unknown. Exchange is unknown in both. Neither infers identity from a sender's network address or wire ID. Skip notices and malformed input diagnostics go to standard error and produce no event.

For example, listen reports WSJT-X closing like this:

{"spec":"0.1.0","family":"wsjtx","mapping":1,"native_version":"3","kind":"lifecycle","wire_id":"test-instance","context":{"direction":"from_application","exchange":"unknown"},"fields":{"state":"closed"},"native":{"format":"wsjtx_datagram","data":"rbzL2gAAAAMAAAAGAAAADXRlc3QtaW5zdGFuY2U="}}

The same datagram through decode has unknown direction, so it is ambiguous with "fields":{"operation":"close"}.

qg-interop decode --wsjtx close.bin

Common frequencies use integer hertz. WSJT-X clock values use HH:MM:SS.mmm; resolved UTC dates use RFC 3339 with three fractional digits and a final Z. Unresolved or invalid native times leave the corresponding common field absent. Their original bytes remain in native.data.

A missing text field is omitted, native null is JSON null, and empty text is "". Invalid text uses {"utf8_bytes":[255]} or {"utf16_units":[55296]} without replacement characters. Finite binary64 values are numbers; nonfinite values use ieee754: and 16 lowercase hexadecimal digits. Consumers must round floating-point numbers correctly. Object member order does not affect equality.

fields.radio.instance labels the radio instance carried by the family. It is never an authenticated sender identity. Common fields do not extract callsigns or grids from decode text or parse ADIF. Commands have kind: "control" and omit native evidence. Reading a command never sends it.

The library also carries events through qgi: reception appends one via hop with the receiving observer's context while preserving the original event and evidence. Received context and hops remain untrusted. See the protocol reference for validation and limits.
